## 🎨 Charte Graphique Proposée

### Palette de couleurs (sobre, fond clair)

**Fond**
- Background: `#FAFAFA` ou `#F8F9FA` (gris très clair, doux pour les yeux)
- Surface: `#FFFFFF` (blanc pur pour les cards)

**Neutres (hiérarchie de gris)**
- Gray-900: `#1A1A1A` (texte principal, fort contraste)
- Gray-600: `#6B7280` (texte secondaire)
- Gray-300: `#D1D5DB` (bordures)
- Gray-100: `#F3F4F6` (backgrounds secondaires)

**Accents (2 couleurs maximum)**

**Option A : Vert sage + Orange terre**
- Primary: `#2D7A5F` (vert sapin/sage, confiance et stabilité)
- Secondary: `#D97706` (orange terre, énergie sans agression)

**Option B : Indigo foncé + Corail**
- Primary: `#334155` (slate foncé, élégance)
- Secondary: `#F97316` (corail, chaleur)

**Option C : Noir + Vert olive** (ultra sobre)
- Primary: `#000000` (noir pur, minimalisme)
- Secondary: `#84A98C` (vert olive doux)

**États (si nécessaire, dérivés des accents)**
- Success: Variante du Primary (teinte verte)
- Error: `#DC2626` (rouge sobre, uniquement pour erreurs)

**Pas de gradients** — couleurs plates uniquement

---

### Typographie

**Titres**
- Font: **Inter** ou **Manrope** (géométrique, moderne)
- Weights: 700-800 (Bold/ExtraBold)
- Taille H1: 3.5rem → 4rem (mobile → desktop)
- Line-height: 1.1

**Corps de texte**
- Font: **Inter** ou **System UI**
- Weight: 400-500 (Regular/Medium)
- Taille: 1rem → 1.125rem
- Line-height: 1.6

**Code snippets**
- Font: **JetBrains Mono** ou **Fira Code** (ligatures)
- Weight: 400
- Background: `rgba(0, 0, 0, 0.05)`

---

### Design System - Composants (sobres)

**Boutons**
```
Primary CTA:
- Padding: 0.75rem 1.5rem
- Border-radius: 0.375rem (arrondi modéré)
- Border: 1px solid [couleur accent]
- Background: [couleur accent]
- Hover: Background légèrement plus foncé (10%)
- Active: Opacity 0.9
- ❌ Pas de shadow
- ❌ Pas de scale
```

**Cards**
```
- Background: white
- Border: 1px solid #E5E7EB (gray-200)
- Border-radius: 0.5rem
- Shadow: ❌ Aucune (ou très légère : 0 1px 2px rgba(0,0,0,0.05))
- Hover: Border color → accent color
- Transition: border-color 0.2s ease
```

**Icons**
- Style: **Lucide** (outline, épuré)
- Size: 20-24px
- Stroke-width: 1.5px
- ❌ Pas d'animation au hover

---

### Micro-Interactions Clés (sobres et subtiles)

1. **Page load**
   - Fade in simple sur tout le contenu (opacity 0 → 1, 400ms)
   - Pas d'animation mot par mot

2. **Scroll**
   - ❌ Pas de parallax
   - ❌ Pas de progress bar
   - ✅ Elements reveal discret (fade up 20px, intersection observer)
   - Transition: `opacity 0.4s ease-out, transform 0.4s ease-out`

3. **Hover states** (minimalistes)
   - Cards: Bordure change de couleur (gray → accent), pas de lift
   - Buttons: Background légèrement plus foncé (5%), pas de scale
   - Links: Soulignement simple qui apparaît

4. **Click interactions**
   - ❌ Pas de ripple
   - ❌ Pas d'haptic
   - ✅ Feedback visuel minimal (active state avec opacity)

5. **Transitions entre sections**
   - Smooth scroll natif (`scroll-behavior: smooth`)
   - ❌ Pas de blur/unblur
   - ❌ Pas de sticky progressif

---

---

### Responsive Strategy

**Mobile-first approach**
- Navigation: hamburger menu (slide-in)
- Hero: text au-dessus, visual réduit
- Cards: stack vertical
- Font-sizes: scale down (16px base)

**Tablet (768px+)**
- 2 colonnes pour benefits
- Visual side-by-side pour "How it Works"

**Desktop (1024px+)**
- 3 colonnes pour value props
- Parallax actif
- Hover states complets

## 🚀 Implémentation Technique (sans détails infra)

**Stack suggérée pour la landing**
- Framework: **Astro** (perf maximale, SSG)
- Styling: **Tailwind CSS 4** (utilité + JIT)
- Animations: **Framer Motion** ou **GSAP** (micro-interactions)
- Icons: **Lucide React**
- Fonts: **Google Fonts** (Inter + JetBrains Mono)

**Performance targets**
- Lighthouse: 95+ sur toutes métriques
- First Contentful Paint: < 1s
- Time to Interactive: < 2s
- Bundle size: < 100KB (gzipped)
